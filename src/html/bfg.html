Set Nickname

Specify the battery nickname used to identify this battery on this page as well as the BFG OLED display. Names must be 11 characters or less

Select battery manufacturer

The battery manufacturer is used by the BFG to improve the batery health and state of charge estimates.

Set Calibration values

Manually specify BFG calibration values. Advanced users only. These values generally should only be modified after contacting Playing With Fusion Technical Support

Modify Battery Age and Capacity

Manually modify the battery age, capacity, and number of charge/discharge cycles. This can be necessary when installing the BFG onto a used battery.

Reset BFG (New Battery)

Reset all battery statistics and battery capacity information in the BFG.

This should only be done when moving a BFG to a new battery. This operation cannot be undone. Once the BFG is reset, the battery capacity will be changed to the full design capacity for the selected manufacturer.

Type "BOMBSAWAY" in the text box below if you wish to proceed

Download BFG Data or Post to the Cloud

Download all battery statistics to a local JSON file or post that data to Playing With Fusion (Internet connection required).

This collection may also include potentially personally identifiable information such as your team number, match number, event name, and submission timestamp. PWF reserves the right to make this data publicly available in the future (for example, through leaderboards, datasets, or analysis tools). Optionally, you may provide an email address, which will only be used for promotional purposes—such as notifying winners of the Random Robot Statistics Competition—and will never be sold, rented, or shared publicly.
